# OctoAcme Project Management Documentation

Welcome to the OctoAcme project management knowledge base. This directory contains comprehensive guides for running projects across all phases of delivery—from initial ideation through post-release retrospectives.

## Core Principles

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Lead
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning

## Project Lifecycle Overview

OctoAcme's project management approach is structured around five interconnected phases:

1. **Initiation** – Validate business need, identify stakeholders, define success metrics, and make the go/no-go decision
2. **Planning** – Break work into shippable increments, estimate scope, identify dependencies, and create a release plan
3. **Execution & Tracking** – Manage day-to-day progress, maintain team rhythm through standups and syncs, track metrics
4. **Release & Deployment** – Standardize releases, manage pre-release verification, coordinate go-live, and plan rollbacks
5. **Retrospectives & Continuous Improvement** – Capture learnings, convert to action items, and measure impact of improvements

Each phase is supported by clear ceremonies, artifacts, and decision gates to ensure consistent, repeatable project execution.

## Key Templates & Artifacts

- **Project One-pager** – Problem statement, goal, success metrics, team, timeline (see [Initiation guide](./octoacme-project-initiation.md))
- **Backlog Item Template** – Title, description, acceptance criteria, estimate, priority, owner (see [Planning guide](./octoacme-project-planning.md))
- **Risk Register** – ID, description, impact, likelihood, owner, mitigation, status (see [Risk Management guide](./octoacme-risks-and-communication.md))
- **Weekly Status Template** – Progress, next steps, risks, decisions needed (see [Risk Management guide](./octoacme-risks-and-communication.md))
- **Release Notes Template** – Release name, date, summary, notable changes, migration steps, known issues (see [Release guide](./octoacme-release-and-deployment.md))
